# Book Tracker – Трекер прочитанных книг

**Автор:** Анастасия
## Описание программы
Book Tracker – это графическое приложение для ведения списка прочитанных книг.  
Позволяет добавлять книги с указанием названия, автора, жанра и количества страниц,  
фильтровать их по жанру и по условию «больше 200 страниц», а также удалять записи.  
Данные сохраняются в файле `books.json` и автоматически загружаются при запуске.

## Инструкция по запуску
1. Убедитесь, что установлен Python версии 3.7 или выше.
2. Скачайте все файлы проекта в одну папку.
3. Откройте терминал в этой папке и выполните:
   ```bash
   python book_tracker.py
